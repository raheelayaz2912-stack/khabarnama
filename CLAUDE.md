PROJECT DECISIONS (resolved conflicts between this file and the original build spec)

These two points in this CLAUDE.md conflicted with the original KHABARX build
spec. Both were explicitly resolved with the project owner on 2026-08-29:

1. LOGO (Section 2): The logo does NOT emphasize a standalone "X". The
   wordmark "KHABARX" is rendered in a single uniform color/weight; only the
   separate icon mark (a layered document/flag glyph, not a letter shape)
   carries the brand gold/red accent color.

2. URL STRUCTURE (Sections 20/21/42): This project intentionally keeps ONE
   URL per bilingual story (e.g. /news/[slug]), with the English and Urdu
   versions of the article on the same page, divided by "the seam." It does
   NOT split into /en/ and /ur/ paths with hreflang. This was the explicit,
   repeated requirement in the original build spec ("Do not create /en/... 
   and /ur/... for the same article unless there is a specific future SEO
   requirement... The core product is: ONE STORY, ONE URL, TWO LANGUAGE
   SECTIONS"). Any future work should preserve this unless the project owner
   explicitly overrides it again.

All other sections of this CLAUDE.md apply as written.
